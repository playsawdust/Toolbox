# Chipper Toolbox

A somewhat opinionated collection of assorted utilities for Java 8/17/25.

Toolbox was originally designed for use alongside Google Guava, but:

* as of 2.2.0, no longer depends on it
* as of 2.3.0, has started growing replacements for some of its features

Guava is a very large dependency and is shackled to Google, who have been pushing generative AI. Toolbox is completely AI-free (as with all of our projects).

Toolbox has a long and storied history being carried around between various projects. The first inklings of it appeared in 2012, before assuming its final form as Toolbox under the Chipper project in 2019. It's more or less a personal utilities library for Falkreon and Exa, but you're invited to use it as well if you're interested!

***Toolbox is no longer on GitHub.*** Please head over to the [Forgejo repo](https://git.sleeping.town/exa/Toolbox). You can make issues and PRs using a GitHub account.
